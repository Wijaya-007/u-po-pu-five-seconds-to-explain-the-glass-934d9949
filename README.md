A tiny Node 22 (stdlib-only) program that writes one sentence — what a house cat says in the five seconds after sweeping a glass off the table — to `/output/entry.txt` and prints it to stdout.

## Run

```sh
node main.ts
```

> Gravity did that. I was conducting a routine stability audit, and the glass failed. File your complaint with physics.
